# 역삼동이선생 블로그 자동 초안 생성기

매일 아침 주제를 골라 초안을 쓰고, Blogger에 **초안(draft)으로만** 올린다.
발행 버튼은 사람이 누른다.

- 블로그: https://63lee.blogspot.com/
- 니치: 커리어(주축) + 브랜드·리테일(보조)
- 프로젝트 위치: `G:/내 드라이브/blog-auto`
- 초안 저장: `G:/내 드라이브/blog-drafts/날짜/`

## 동작 방식

```
Google Trends 일간 인기검색어 ──┐
                              ├─→ 니치 필터 → 주제 선정 → Claude 초안 (3,000자+)
에버그린 주제 풀 (niche.py) ────┘                          │
                                                          ├─→ 인용 카드 PNG 2장 + 스톡 사진
                                                          ├─→ 검수용 HTML 저장 (G드라이브)
                                                          └─→ Blogger 초안 업로드
```

한국 일간 트렌드 상위는 대부분 스포츠·연예라서 니치 필터를 통과하는 날이 드물다.
평소에는 **에버그린 주제가 주력**이고, 트렌드는 걸리는 날에만 얹힌다.
이건 버그가 아니라 의도된 설계다 — 트렌드 키워드는 CPC가 낮고 하루면 검색량이 사라진다.

## 이미지

- **인용 카드** — 본문의 핵심 문장 2개를 뽑아 1200×630 PNG로 직접 그린다.
  저작권 문제가 없고 글 내용과 정확히 맞는다. 별도 설정이 필요 없다.
- **도입부 스톡 사진** — Pexels에서 받는다. 상업적 이용과 핫링크가 허용된다.
  `.env`의 `PEXELS_API_KEY`가 비어 있으면 이 단계만 건너뛴다.

Blogger API에는 이미지 업로드가 없다. 파일로 저장만 하고, 검수하면서
Blogger 편집기에 드래그해 넣는다. 검수용 HTML 하단에 미리보기가 붙어 있다.

## 출장 중 다른 PC에서 쓰기

프로젝트가 구글 드라이브에 있어서 폴더는 어디서든 열린다. 다만 새 PC에서는
Python과 패키지를 한 번 설치해야 한다.

```bash
pip install -r requirements.txt
```

`.env`와 `token.json`이 함께 동기화되므로 키를 다시 넣을 필요는 없다.

## 최초 설정 (1회)

### 1. Anthropic API 키

1. https://console.anthropic.com 가입 후 로그인
2. **Settings → API keys → Create Key**
3. 결제 수단 등록 (Billing). 최소 $5부터 충전 가능
4. `sk-ant-`로 시작하는 키를 복사 — **이때 한 번만 보인다**

### 2. Blogger API 사용 설정

1. https://console.cloud.google.com 접속
2. 상단에서 **프로젝트 만들기** (이름 아무거나, 예: `blog-auto`)
3. **API 및 서비스 → 라이브러리** → "Blogger API v3" 검색 → **사용 설정**
4. **API 및 서비스 → OAuth 동의 화면**
   - User Type: **외부** 선택 → 만들기
   - 앱 이름, 사용자 지원 이메일, 개발자 이메일만 채우고 저장
   - **대상(Audience) → 테스트 사용자**에 본인 구글 계정 추가
5. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   - 애플리케이션 유형: **데스크톱 앱**
   - 만들고 나서 **JSON 다운로드**
6. 받은 파일을 이 폴더에 **`client_secret.json`** 이름으로 저장

### 3. 설정 파일

```bash
copy .env.example .env
```

`.env`를 열어 `ANTHROPIC_API_KEY`를 채운다.
`PEXELS_API_KEY`는 https://www.pexels.com/api/ 에서 무료로 받는다 (선택).

> 경로를 직접 수정할 때는 **역슬래시 대신 슬래시**를 쓴다.
> `G:\내 드라이브`(역슬래시)처럼 쓰면 `\내`가 이스케이프 문자로 해석돼 경로가 깨진다.

### 4. 구글 계정 연결

> **테스트 사용자 등록을 빠뜨리면 여기서 막힌다.** 3단계의 대상(Audience) 메뉴에서
> 본인 계정을 테스트 사용자로 추가하지 않으면 "액세스 차단됨: 403 access_denied"가 뜬다.


```bash
python setup_blogger.py
```

브라우저가 열리면 로그인하고 권한을 허용한다.
("Google에서 확인하지 않은 앱" 경고가 뜨면 **고급 → 안전하지 않은 페이지로 이동**.
본인이 만든 앱이라 정상이다.)

끝나면 화면에 `BLOG_ID=...`가 출력된다. 이 줄을 `.env`에 넣는다.

## 실행

```bash
python run.py              # 초안 작성 + Blogger 업로드
python run.py --no-upload  # 로컬에만 저장 (테스트용)
```

결과물 (`G:/내 드라이브/blog-drafts/YYYY-MM-DD/`):
- `01-제목.html` — 제목 후보 3개, 메타 설명, 라벨, **팩트체크 목록**이 상단 박스에 붙어 있다
- `01-images/card1.png`, `card2.png` — 인용 카드
- `01-images/hero.jpg` — 도입부 사진 (Pexels 키가 있을 때)
- Blogger 관리자 → 게시물 → 초안


## 이미 만든 초안을 Blogger에 올리기

매일 자동 실행은 생성과 동시에 올린다. 예전에 만들어둔 초안을 뒤늦게 올릴 때만 쓴다.

```bash
python upload_drafts.py "G:/내 드라이브/blog-drafts/출장-예약분/2026-09-07"
```

`--dry-run`을 붙이면 올릴 목록만 보여준다. 이미 올린 글은 `data/uploaded.json`에
기록돼 다시 올리지 않으므로, 중간에 끊겨도 같은 명령을 다시 실행하면 이어서 올린다.

### 속도 제한 주의

Blogger는 짧은 시간에 글을 여러 개 만들면 **429 → 403 순으로 막는다.**
한 번 막히면 몇 시간 풀리지 않는다. 그래서 글 사이에 15초 간격을 두고,
429가 나오면 30초·90초·240초로 늘려가며 기다린다.

**막혔을 때 계속 재시도하면 차단이 더 길어진다.** 업로더는 403을 만나면
그 자리에서 멈추도록 해뒀다. 몇 시간 뒤에 다시 실행하면 된다.

400 오류는 대개 라벨이 원인이다. 이때는 라벨을 절반으로, 그래도 안 되면
라벨 없이 올린다. 본문을 살리는 쪽이 우선이기 때문이다.

## 매일 아침 자동 실행

Windows 작업 스케줄러에서:

1. **작업 만들기** (기본 작업 아님)
2. 일반: 이름 `블로그 초안 생성`, **사용자가 로그온했을 때만 실행**
3. 트리거: 매일 오전 7시
4. 동작: 프로그램 시작 → `run_daily.bat` 경로 지정, **시작 위치**에 이 폴더 경로 입력
5. 조건: "컴퓨터의 AC 전원이 켜져 있는 경우에만" 체크 해제
6. 트리거에 **5~10분 지연**을 준다 — 구글 드라이브가 연결된 뒤에 실행돼야 한다
   (드라이브가 준비되지 않으면 프로젝트 폴더의 `output/`으로 저장된다)

## 발행 전 체크리스트

자동 생성물을 그대로 발행하면 안 된다. **매일 5분만 쓰면 된다.**

- [ ] 상단 박스의 **팩트체크 목록**을 확인한다. 수치 하나가 글 전체의 신뢰를 무너뜨린다
- [ ] 제목 후보 3개 중 하나를 고른다 (또는 직접 고쳐 쓴다)
- [ ] **훅 문단에 본인의 실제 경험을 넣는다.** 이게 가장 중요하다.
      AI가 지어낸 장면을 그대로 두면 글이 공허해지고, Google의
      "대량 자동 생성 콘텐츠" 정책에도 걸린다
- [ ] `01-images/` 폴더의 이미지를 Blogger 편집기에 드래그해 넣는다
      (도입부에 사진, 본문 중간에 인용 카드)

## 비용

초안 1건당 Claude API 약 $0.10~0.15 (3,000자 + 확장 패스 포함).
하루 2건이면 **월 $6~9** 수준이다. Pexels와 Blogger API는 무료다.
